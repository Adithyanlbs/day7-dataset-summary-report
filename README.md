# Day 7 – Dataset Summary Report

A Pandas-based dataset analysis project created as part of the Day 7 assignment.

## Dataset

The project uses a student dataset stored in CSV format.

## Analysis Performed

- Loaded CSV data using Pandas
- Inspected the first rows using `head()`
- Inspected the last rows using `tail()`
- Viewed random samples using `sample()`
- Checked dataset shape
- Examined column names
- Examined DataFrame index
- Checked data types using `dtypes`
- Generated dataset information using `info()`
- Generated descriptive statistics using `describe()`
- Identified missing values using `isna()` and `sum()`
- Identified numeric and non-numeric columns
- Recorded basic observations about the dataset

## Files

- `Day7_Dataset_Summary_Report.ipynb` – Pandas analysis notebook
- `Day7_Student_Dataset.csv` – Dataset used for the analysis
